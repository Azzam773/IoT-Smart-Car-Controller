# IoT-Smart-Car-Controller
IoT Smart Car Controlled by Node-RED using MQTT and ESP-01.
Project Overview
This project is an IoT-based smart car controlled through a Node-RED Dashboard. The system uses an ESP-01 Wi-Fi module to connect an Arduino Uno to a local MQTT broker. Node-RED publishes movement commands, and the Arduino controls the DC motors through an L298N motor driver.
The project is an upgraded version of a Bluetooth-controlled smart car. The original HC-05 Bluetooth control was extended with Wi-Fi, MQTT, Node-RED Dashboard control, and optional notification services.
